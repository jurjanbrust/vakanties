# 🧳 Vakanties

Overzicht van onze vakantieprogramma's. Elke vakantie heeft een eigen submap met een volledig dagprogramma (routes, foto's, openingstijden, eten & tips).

## Reizen

* [🇬🇧 Londen 2026 (31 juli – 5 augustus)](./London-2026/README.md)

## Hoe werkt dit?

Elk programma is opgebouwd met hulp van GitHub Copilot CLI volgens een vaste, herbruikbare aanpak (sfeerfoto's, routes met tijd/afstand/vervoersicoon, achtergrondinfo per bezienswaardigheid, weer, eten, tickets). Zie [`PROMPT.md`](./PROMPT.md) voor de volledige instructie die je opnieuw kunt gebruiken voor een nieuwe vakantie — kopieer die instructie, geef Copilot je ruwe programma/ideeën, en laat een nieuwe submap genereren.
